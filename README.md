# discord-nitro-sniper

I got tired of electron-based snipers eating 500MB RAM and leaking my token to some sketchy backend. This is a dead-simple headless sniper that connects to Discord's gateway, watches for gift links, and redeems them faster than I can blink.

## install

pip install -r requirements.txt

## usage

python sniper.py --token YOUR_USER_TOKEN
